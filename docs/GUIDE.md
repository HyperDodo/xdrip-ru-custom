# Полный гайд: xDrip+ RU custom (Libre 2 Gen2 + калибровки)

Документ описывает установку, настройку и использование кастомной сборки xDrip+ для FreeStyle Libre 2 российского региона (Gen2): мост Juggluco, калибровки, интеграции и решение проблем.

Сборка собрана из NightscoutFoundation/xDrip @ `e1407ec` (Sep 2026), ветка `ru-custom` (коммит сборки `718d082`, тег `ru-custom-2026.09.16`).

## 1. Что это и как работает

xDrip+ не может читать Libre 2 Gen2 напрямую: у Gen2 новая криптография (новые NFC-команды и challenge/response плюс защищённая Bluetooth-сессия), открытой реализации которой нет. Поэтому данные идут через посредника:

```
Libre 2 Gen2 (RU)
   |  один NFC-скан при подключении, дальше Bluetooth
   v
Juggluco (читает сенсор)
   |  трансляция "Patched Libre" (broadcast)
   v
xDrip+ (эта сборка), источник данных "Libre2 Patched"
   |  график, тревоги, калибровки, Nightscout, AAPS
```

Что изменено относительно стока:

- Gen2 определяется как отдельный тип сенсора; NFC-скан Gen2 завершается понятным сообщением вместо ошибочного "libre1 failsafe" (сообщение: используйте мост).
- Калибровки для Libre-источников: пункт "Add Calibration" доступен в меню, и калибровка применяется ко всем путям данных источника "Libre2 Patched" (realtime, scan, history), которые в стоке её игнорировали.

Что НЕ изменено: Dexcom и другие источники, путь Libre 2 EU (OOP2), поведение режима "No calibration" (байт в байт как в стоке).

## 2. Требования

- Телефон: Android 8.0+ (API 26). Root не нужен.
- Сенсор: Libre 2 Gen2 (RU / Eastern / ROW) с мостом Juggluco, либо Libre 2 EU (прямой путь, как в стоке).
- Juggluco (juggluco.nl) для Gen2. Для EU-пути: OOP2, как обычно.
- Bluetooth и NFC на телефоне.

## 3. Установка

1. Если установлен официальный xDrip+ или другая сборка с другой подписью: сначала удали её. Эта сборка подписана локальным ключом, Android не даст поставить её поверх чужой подписи.
   - Если нужна история: в старом приложении меню -> Export DB. Файл сохрани в надёжное место.
2. Установи `xdrip-ru-gen2-calibration.apk` (разреши установку из неизвестных источников для файлового менеджера или браузера).
3. Открой приложение и выдай разрешения: уведомления, "Устройства поблизости" / Bluetooth.
4. Настройки Android -> Батарея: для xDrip и для Juggluco поставь "Без ограничений" (иначе Android будет обрезать фоновую работу, и появятся дырки в данных).
5. Если переносил историю: меню -> Import DB.
6. Проверь, что в приложении верная версия: About / версия должна показывать `718d082-ru-custom-2026.09.16`.

## 4. Настройка для Gen2 (RU) через Juggluco, пошагово

1. Активируй сенсор обычным способом (приложение LibreLink или считыватель FreeStyle). Juggluco подключается к уже активированному сенсору, привязку он не делает.
2. Установи Juggluco (juggluco.nl). Открой его и отсканируй сенсор по NFC один раз. Дальше Juggluco читает сенсор по Bluetooth: держи Bluetooth включённым.
3. Убедись, что в Juggluco идут значения (список или график заполняется).
4. В Juggluco: настройки -> трансляции глюкозы -> включи **"Patched Libre"**. Трансляцию "xDrip" для этого сценария включать не нужно.
   - Когда Juggluco спросит данные о пакете xDrip, укажи `com.eveningoutpost.dexdrip` и сохрани.
5. В xDrip: открой мастер источников (Settings -> source wizard) и выбери Libre -> **"Libre2 Patched"**.
6. В xDrip: меню (гамбургер) -> Start sensor -> ответь **"Not today"**. Это только регистрация сенсора внутри xDrip; физически с сенсором ничего не происходит.
7. Через несколько минут появятся показания. Мост транслирует значения, усреднённые за короткое окно, так что первая точка появится не мгновенно.
8. Если сенсор допускает только одно Bluetooth-подключение и LibreLink перехватывает связь: отбери у LibreLink разрешение "Устройства поблизости", чтобы он не боролся с Juggluco. (Данные LibreLink при этом не нужны, сенсор читает Juggluco.)

Чего НЕ делать:

- Не пытайся считать Gen2 через NFC в xDrip: приложение специально останавливается и пишет использовать мост. Это нормальное поведение, а не ошибка.
- Не настраивай OOP2 для Gen2: это тупиковый путь (как и в стоке xDrip), он не работает с Gen2.

## 5. Libre 2 EU: прямой путь (как в стоке)

Если у тебя сенсор EU-региона (например, `7F 0E 30/31`, `C6 09 31`, `9D 08 30`, `C5 09 30`), всё как в обычном xDrip: установи OOP2, выбери источник Libre2 (NFC-старт) и пользуйся. Отличие этой сборки только одно: пункт "Add Calibration" теперь всегда доступен для Libre-источников, пока калибровка включена (см. следующий раздел).

## 6. Калибровки: как пользоваться

Как включить/выключить калибровку:

- Настройки -> поиск "calibrate" (в русской локали "калибров").
- **"Calibrate based on raw"** (по умолчанию) и **"Calibrate based on glucose"** (экспериментальный): оба включают калибровку для данных моста.
- **"No calibration"** ("Без калибровки"): калибровка не применяется, пункт "Add Calibration" скрывается; данные моста вставляются как есть (поведение как в стоке).

Как откалибровать:

1. Дождись, чтобы пришло хотя бы одно показание из моста и появилась запись сенсора в xDrip. Без данных пункт калибровки может быть недоступен.
2. Меню (гамбургер) -> **Add Calibration**.
3. Введи значение с глюкометра. Если приложение в режиме mg/dL, значение вводится в mg/dL (для начальной двойной калибровки допустимый диапазон 40-400).
4. Готово: калибровка применится к новым показаниям из моста.

Как это работает внутри (важно понимать пределы):

- Калибровка Libre в xDrip **только смещение**: наклон фиксирован (slope = 1), смещение ограничено диапазоном **-40 .. +20 mg/dL**. Это дизайн xDrip для Libre (класс `Li2AppParameters`), не особенность сборки.
- Если расхождение с глюкометром больше этих пределов, компенсировать его калибровкой не получится: проверь сенсор, глюкометр и стабильность момента (резкие перепады, еда, компрессия сенсора).
- Калибровка моста это вторая ступень поверх значений, которые уже рассчитал Juggluco.
- После первой калибровки сдвигаются будущие показания; после второй недавние показания пересчитываются; перезапись более старой истории зависит от настройки "rewrite history".
- В стоке свежая установка xDrip с Libre-источником предлагала только "Initial calibration" или вообще ничего; в этой сборке "Add Calibration" всегда доступен, пока калибровка включена.

Если калибровка не нужна: включи "No calibration", и поведение будет как в стоковом xDrip.

## 7. Тревоги, выгрузка, AAPS, часы

- Тревоги, Nightscout и остальные функции работают как в обычном xDrip: настраиваются стандартно.
- AndroidAPS: получает данные из xDrip штатным образом. Если хочешь калибровать из AAPS: в xDrip Settings -> Inter-app settings включи "Accept calibrations", а "Upload treatments" оставь выключенным (как требуют доки AAPS).
- Часы (Wear OS): данные на часы приходят через обычную настройку xDrip Wear. Одна оговорка: в wear-модуле нет строки с подсказкой про мост, поэтому скан Gen2 с часов не покажет это сообщение (на телефоне покажет). Таблица типов сенсоров на часах обновлена.

## 8. Обновление и откат

- Обновление поверх: только сборками с той же подписью (локальный ключ этой сборки). Обычная установка APK поверх.
- Откат на официальный xDrip+: удали эту сборку, установи официальную, затем Import DB (сделанный заранее Export DB), если нужна история.
- Переезд с официальной на эту: Export DB в старой, удалить, установить эту, Import DB.

## 9. Решение проблем

| Проблема | Причина / что делать |
|---|---|
| В xDrip нет показаний | Проверь цепочку: Juggluco показывает значения? "Patched Libre" включён? Пакет `com.eveningoutpost.dexdrip` указан? В xDrip источник "Libre2 Patched"? Start sensor сделан ("Not today")? Батарея без ограничений у обоих приложений? Дай пару минут. |
| Показания пропадают, дырки в графике | Ограничения фоновой работы Android: разреши "без ограничений" в батарее, разреши "Устройства поблизости", проверь, что LibreLink не отбирает Bluetooth-соединение (отбери у него разрешение). |
| Пункт "Add Calibration" отсутствует | Ещё нет данных (нужна запись сенсора и показание) или калибровка выключена ("No calibration"). |
| Калибровка "не помогает" | Она только смещение и ограничена -40..+20 mg/dL. Если расхождение больше, калибровка упрётся в предел: проверь сенсор/глюкометр. |
| После калибровки график не изменился | Пересчёт применяется к новым показаниям; подожди следующих данных из моста. |
| NFC-скан Gen2 в xDrip "не работает" | Так и должно быть: Gen2 читает Juggluco, xDrip только принимает поток. Сообщение при скане это подсказка, а не ошибка. |
| Скан с часов ничего не пишет | Ожидаемо: подсказки про мост в wear-модуле нет (на телефоне есть). |
| Нужно проверить целостность APK | Посчитай sha256 и сравни с `8dcb4973252392c749385498e6199eebe2d4fca638ff972d6198c38bc6f4d5cb`: `sha256sum xdrip-ru-gen2-calibration.apk` (Linux/macOS) или `Get-FileHash -Algorithm SHA256 xdrip-ru-gen2-calibration.apk` (Windows). |

## 10. Известные ограничения (честный список)

- Gen2 нельзя читать напрямую, пока нет открытой реализации его крипто; без Juggluco сборка для Gen2 бесполезна.
- OOP2 с Gen2 не работает (как и в стоке).
- Калибровка моста это вторая ступень поверх расчёта Juggluco, только смещение.
- Watch (wear) модуль: таблица типов сенсоров обновлена, но подсказки при скане нет.
- В режиме калибровки истории моста вставляется по точкам (без spline-заполнения пропусков), это небольшая разница со стоковым поведением для history-пути.
- В режиме "No calibration" остаточная калибровка на realtime-пути моста ведёт себя как в стоке (не трогалось, чтобы не менять поведение).
- Живой end-to-end прогон на реальном сенсоре не выполнялся (не было сенсора в среде сборки). Проверено: код, 20/20 тестов, содержимое APK. Отчёт: docs/verification-report.md.
- DIY: не медицинское изделие, решения по дозам только по проверенным значениям.

## 11. Сборка из исходников и тесты

- Ветки: `ru-custom` (финал, оба патча), `ru-gen2`, `libre2-calibration` (патчи по отдельности), `verify-tests` (тесты), `master` (база).
- Требования: JDK 17, Android SDK (platform 34, build-tools 35 или 36).
- Сборка: `./gradlew.bat :app:assembleDebug` (Windows, все флейворы) или `:app:assembleProdRelease` для релиза; на Linux/macOS `./gradlew ...`. Подпись релиза настраивается через untracked `app/local.gradle` (иначе релиз соберётся без твоей подписи).
- Тесты: `./gradlew.bat :app:testProdDebugUnitTest`. Верификация прогонялась в production-equivalent режиме (assertions выключены): 20/20 зелёные.
